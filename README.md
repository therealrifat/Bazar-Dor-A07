## 📋 Short Description
**বাজার দর (BazarDor)** হলো একটি আধুনিক এবং ব্যবহারকারী-বান্ধব প্ল্যাটফর্ম, যার মাধ্যমে চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম ও মসলার মতো নিত্যপ্রয়োজনীয় পণ্যের বর্তমান বাজারদর খুব সহজেই এক জায়গায় দেখা যায়। এই অ্যাপটির সাহায্যে ব্যবহারকারীরা প্রতিদিনের পণ্যের দামের উঠানামা, দাম বৃদ্ধি বা হ্রাসের শতকরা হার এবং বাজারভিত্তিক বিস্তারিত তথ্য সহজেই ট্র্যাক করতে পারেন।

## 🛠️ Technologies Used
This project is built using modern web technologies to ensure fast performance and a responsive user experience:
* **Frontend Framework:** Next.js / React
* **Styling:** Tailwind CSS / CSS Modules
* **Deployment:** Vercel

---

## ✨ 5 Key Features
1. **Live Price Tracking & Updates:** View up-to-date daily market prices for a wide range of essential commodities.
2. **Category-wise Browsing:** Easily filter and browse products through categorized sections (e.g., Rice, Lentils, Oil, Vegetables, Fish, Meat, Dairy, and Spices).
3. **Price Fluctuation Indicators:** Quickly identify which items have seen a price hike (▲) or drop (▼) along with their exact percentage changes.
4. **User Authentication:** Sign in and Sign up capabilities to access personalized features or account settings.
5. **Responsive & Intuitive UI:** A clean, fast, and mobile-friendly interface designed for a seamless user experience across all devices.
